# 07 - 认证与授权

认证与授权是Web应用安全的两大核心支柱。本文将详细探讨miniblog项目中如何实现一个完善的认证授权系统。

## 1. 认证与授权的概念

### 1.1 基本概念区分

- **认证(Authentication)**：确认用户是谁（验证身份）
- **授权(Authorization)**：确定用户能做什么（验证权限）

简单记忆：
- 认证解决"你是谁"的问题
- 授权解决"你能做什么"的问题

### 1.2 认证与授权的流程

典型的Web应用认证授权流程：

1. 用户提供凭证（如用户名和密码）
2. 服务器验证凭证的有效性
3. 验证成功后颁发令牌（如JWT）
4. 用户后续请求携带令牌
5. 服务器验证令牌并确定用户权限
6. 根据用户权限决定是否允许访问资源

## 2. JWT认证

### 2.1 JWT的基本结构

JWT(JSON Web Token)是一种紧凑的、自包含的、基于JSON的标准(RFC 7519)，用于在网络应用环境间安全地传递声明。

JWT由三部分组成，以点（.）分隔：
- **Header**：包含令牌类型和使用的算法
- **Payload**：包含声明（如用户ID、角色、过期时间等）
- **Signature**：用于验证令牌的完整性

### 2.2 JWT的优势

- **无状态**：服务器不需要存储会话信息
- **可扩展**：可以在多个服务之间共享
- **安全性**：使用签名确保数据不被篡改
- **信息丰富**：可以包含用户信息和授权数据

### 2.3 JWT的工作流程

![JWT工作流程](https://cdn.auth0.com/content/jwt/jwt-diagram.png)

1. 用户登录成功后，服务器生成JWT
2. 服务器将JWT返回给客户端
3. 客户端存储JWT（通常在localStorage或Cookie中）
4. 客户端的后续请求在Authorization头中附带JWT
5. 服务器验证JWT的签名和有效性
6. 验证通过后，从JWT中提取用户信息和权限信息

## 3. 实现认证中间件

### 3.1 JWT认证中间件

JWT认证中间件负责拦截请求，验证JWT的有效性，并将用户信息提取到请求上下文中：

```go
// Authn 认证中间件，验证请求中的JWT令牌
func Authn() gin.HandlerFunc {
    return func(c *gin.Context) {
        // 从请求头获取Token
        token := c.Request.Header.Get("Authorization")
        if token == "" {
            c.AbortWithStatusJSON(http.StatusUnauthorized, gin.H{
                "code": errno.ErrTokenInvalid.Code,
                "message": "请求未携带Token，无权访问",
            })
            return
        }
        
        // 去掉Bearer前缀（如果有）
        token = strings.TrimPrefix(token, "Bearer ")
        
        // 验证Token
        claims, err := auth.Parse(token)
        if err != nil {
            c.AbortWithStatusJSON(http.StatusUnauthorized, gin.H{
                "code": errno.ErrTokenInvalid.Code,
                "message": "无效的Token",
            })
            return
        }
        
        // 将用户信息存入上下文
        c.Set(known.XUsernameKey, claims.Username)
        c.Set(known.XUserIDKey, claims.ID)
        c.Set(known.XRoleKey, claims.Role)
        
        c.Next()
    }
}
```

### 3.2 RBAC授权中间件

RBAC(Role-Based Access Control，基于角色的访问控制)是一种常用的授权模型：

```go
// Authz 授权中间件，基于RBAC模型控制资源访问
func Authz(requiredRole string) gin.HandlerFunc {
    return func(c *gin.Context) {
        // 从上下文获取用户角色
        role, exists := c.Get(known.XRoleKey)
        if !exists {
            c.AbortWithStatusJSON(http.StatusForbidden, gin.H{
                "code": errno.ErrForbidden.Code,
                "message": "没有访问权限，请先登录",
            })
            return
        }
        
        // 检查角色是否满足要求
        if !hasPermission(role.(string), requiredRole) {
            c.AbortWithStatusJSON(http.StatusForbidden, gin.H{
                "code": errno.ErrForbidden.Code,
                "message": "权限不足，无法访问该资源",
            })
            return
        }
        
        c.Next()
    }
}

// hasPermission 检查用户角色是否有权限
func hasPermission(userRole, requiredRole string) bool {
    // 角色层级: admin > editor > reader
    roleWeight := map[string]int{
        "admin":  100,
        "editor": 50,
        "reader": 10,
        "":       0,
    }
    
    return roleWeight[userRole] >= roleWeight[requiredRole]
}
```

## 4. JWT的生成与解析

### 4.1 生成JWT

```go
// Sign 根据用户信息生成JWT令牌
func Sign(user *model.User) (string, error) {
    // 获取当前时间
    now := time.Now()
    
    // 创建Claims
    claims := jwt.RegisteredClaims{
        ExpiresAt: jwt.NewNumericDate(now.Add(24 * time.Hour)), // 24小时后过期
        IssuedAt:  jwt.NewNumericDate(now),
        NotBefore: jwt.NewNumericDate(now),
        Subject:   user.Username,
    }
    
    // 添加自定义Claims
    customClaims := Claims{
        RegisteredClaims: claims,
        Username: user.Username,
        ID:       user.ID,
        Role:     user.Role,
    }
    
    // 创建令牌
    token := jwt.NewWithClaims(jwt.SigningMethodHS256, customClaims)
    
    // 签名令牌
    return token.SignedString([]byte(secretKey))
}
```

### 4.2 解析JWT

```go
// Parse 解析JWT令牌，返回Claims
func Parse(tokenString string) (*Claims, error) {
    // 创建一个Claims实例
    claims := &Claims{}
    
    // 解析令牌
    token, err := jwt.ParseWithClaims(tokenString, claims, func(token *jwt.Token) (interface{}, error) {
        // 验证签名算法
        if _, ok := token.Method.(*jwt.SigningMethodHMAC); !ok {
            return nil, fmt.Errorf("unexpected signing method: %v", token.Header["alg"])
        }
        // 返回密钥
        return []byte(secretKey), nil
    })
    
    // 处理解析错误
    if err != nil {
        return nil, err
    }
    
    // 验证令牌有效性
    if !token.Valid {
        return nil, errors.New("invalid token")
    }
    
    return claims, nil
}
```

## 5. 用户认证API实现

### 5.1 用户注册

```go
// Register 实现用户注册
func (ctrl *UserController) Register(c *gin.Context) {
    // 绑定请求参数
    var req v1.CreateUserRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        core.WriteResponse(c, errno.ErrBind, nil)
        return
    }
    
    // 创建用户
    user := &model.User{
        Username: req.Username,
        Email:    req.Email,
        Role:     "reader", // 默认为reader角色
    }
    
    // 设置密码（会进行哈希处理）
    if err := user.SetPassword(req.Password); err != nil {
        core.WriteResponse(c, errno.ErrEncrypt, nil)
        return
    }
    
    // 保存用户到数据库
    if err := ctrl.b.Users().Create(c, user); err != nil {
        core.WriteResponse(c, err, nil)
        return
    }
    
    // 返回结果（不返回密码）
    core.WriteResponse(c, nil, user.WithoutPassword())
}
```

### 5.2 用户登录

```go
// Login 实现用户登录
func (ctrl *UserController) Login(c *gin.Context) {
    // 绑定请求参数
    var req v1.LoginRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        core.WriteResponse(c, errno.ErrBind, nil)
        return
    }
    
    // 验证用户身份
    user, err := ctrl.b.Users().GetByUsername(c, req.Username)
    if err != nil {
        core.WriteResponse(c, errno.ErrUserNotFound, nil)
        return
    }
    
    // 验证密码
    if !user.ValidatePassword(req.Password) {
        core.WriteResponse(c, errno.ErrPasswordIncorrect, nil)
        return
    }
    
    // 生成JWT令牌
    token, err := auth.Sign(user)
    if err != nil {
        core.WriteResponse(c, errno.ErrSignToken, nil)
        return
    }
    
    // 返回JWT令牌
    core.WriteResponse(c, nil, v1.LoginResponse{
        Token: token,
        User:  user.WithoutPassword(),
    })
}
```

## 6. 最佳实践与安全考虑

### 6.1 JWT安全性最佳实践

1. **使用HTTPS**：确保所有API通信都通过HTTPS进行，防止令牌被窃取
2. **设置合理的过期时间**：JWT不应该永久有效，通常设置为几小时或几天
3. **刷新令牌**：使用刷新令牌机制延长会话，而不是延长访问令牌的有效期
4. **对敏感操作进行二次验证**：即使用户已认证，敏感操作也应要求二次验证
5. **不在JWT中存储敏感信息**：JWT的Payload部分可以被解码，不应存储敏感数据
6. **使用强密钥**：JWT签名密钥应该足够长且随机

### 6.2 密码存储

永远不要以明文形式存储密码，应使用单向哈希算法如bcrypt：

```go
// SetPassword 设置用户密码，使用bcrypt算法哈希
func (u *User) SetPassword(password string) error {
    hash, err := bcrypt.GenerateFromPassword([]byte(password), bcrypt.DefaultCost)
    if err != nil {
        return err
    }
    u.PasswordHash = string(hash)
    return nil
}

// ValidatePassword 验证密码是否正确
func (u *User) ValidatePassword(password string) bool {
    err := bcrypt.CompareHashAndPassword([]byte(u.PasswordHash), []byte(password))
    return err == nil
}
```

### 6.3 预防常见攻击

1. **防止中间人攻击**：使用HTTPS和短期令牌
2. **防止CSRF攻击**：将令牌存储在HttpOnly Cookie中
3. **防止XSS攻击**：客户端谨慎处理JWT，使用适当的内容安全策略

    assert.Equal(t, http.StatusUnauthorized, w.Code)
    
    // 创建合法token的请求
    validToken := createTestToken(t, "testuser", "admin")
    req = httptest.NewRequest("GET", "/auth-test", nil)
    req.Header.Set("Authorization", "Bearer "+validToken)
    w = httptest.NewRecorder()
    r.ServeHTTP(w, req)
    
    // 验证合法token请求被接受
    assert.Equal(t, http.StatusOK, w.Code)
    assert.Contains(t, w.Body.String(), "testuser")
}
